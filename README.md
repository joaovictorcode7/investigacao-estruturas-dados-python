# Investigação Experimental de Estruturas de Dados e Algoritmos

Projeto acadêmico desenvolvido em Python para estudar algoritmos de ordenação e busca, vetores, matrizes e complexidade computacional.

## Conteúdos
- Bubble Sort e Quick Sort
- Comparações e movimentações
- Busca sequencial em matrizes
- Vetor de temperaturas
- Matriz de sensores
- Análise de complexidade

## Como executar

Com Python 3 instalado:

```bash
python src/atividade.py
```
